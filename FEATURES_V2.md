# 🚀 Telegram Bot v2 - Полная версия

## ✨ Новые функции

### 1. 🔄 Апгрейд/даунгрейд тарифов
- Переход на более высокий тариф с сохранением дней
- Планирование даунгрейда после окончания подписки
- Команда: `/changeplan`

### 2. 🎁 Триал-периоды
- 7 дней бесплатного доступа ко всем функциям
- Автоматическая проверка использования
- Команда: `/trial`

### 3. 🤖 AI-ассистент 24/7
- Ответы на частые вопросы
- Консультации по продукту
- Умный поиск по ключевым словам
- Команда: `/ai`

### 4. 💬 Консультации по продукту
- Описание возможностей сервиса
- Преимущества и тарифы
- Интегрировано в AI-ассистент

### 5. ⭐ Отзывы и рейтинги
- Оценка от 1 до 5 звёзд
- Текст отзыва
- Предложения по улучшению
- Уведомления админам
- Команда: `/review`

### 6. 📰 Push-уведомления о новостях
- Создание новостей для пользователей
- Срочные уведомления
- Рассылка всем пользователям
- Команда: `/news` (для админов)

### 7. 📄 Конвертация документов
- PDF → Текст
- Текст → PDF
- Отправка файлов в бота
- Команда: `/documents`

### 8. 🔍 OCR распознавание текста
- Распознавание текста с фото
- Поддержка русского и английского
- Сохранение результата
- Команда: `/ocr`

### 9. 📝 Шаблонизатор документов
- Шаблоны для типовых документов
- Заполнение переменных
- Генерация готовых документов
- (В разработке)

### 10. 👤 Личный кабинет
- Статистика использования
- История платежей
- Информация о подписке
- Рефералы и отзывы
- Команда: `/account`

## 🛠 Установка

### Шаг 1: Установите зависимости

```bash
pip install -r requirements_v2.txt
```

Для OCR дополнительно установите Tesseract:
- **Windows:** https://github.com/UB-Mannheim/tesseract/wiki
- **Linux:** `sudo apt-get install tesseract-ocr tesseract-ocr-rus`
- **Mac:** `brew install tesseract tesseract-lang`

### Шаг 2: Загрузите на GitHub

Загрузите новые файлы:
- `bot_v2.py`
- `models_v2.py`
- `trial.py`
- `subscription_upgrade.py`
- `ai_assistant.py`
- `reviews.py`
- `documents.py`
- `personal_account.py`
- `notifications_v2.py`
- `keyboards_v2.py`
- `requirements_v2.txt`

### Шаг 3: Обновите main.py

Замените импорт:
```python
from bot_v2 import bot, dp
```

### Шаг 4: Обновите requirements.txt на GitHub

Замените содержимое `requirements.txt` на содержимое `requirements_v2.txt`

### Шаг 5: Пересоберите на Railway

1. Перейдите в **Deployments**
2. Нажмите **⋮** → **Redeploy**
3. Дождитесь завершения

## 🐛 Troubleshooting

### OCR не работает
- Установите Tesseract OCR
- Добавьте в PATH (Windows)
- Установите языковые пакеты: `tesseract-ocr-rus`

### Конвертация PDF не работает
- Проверьте установку PyPDF2: `pip install PyPDF2`
- Для создания PDF: `pip install reportlab`

### Бот не запускается
- Проверьте логи Railway
- Убедитесь, что все зависимости установлены
- Проверьте переменные окружения
