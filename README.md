# Telegram Bot v3 - Земляные работы и НПА

Полнофункциональный Telegram бот для приема заявок на земляные работы с системой вопрос-ответ по нормативно-правовым актам Москвы.

## 🎯 Основные возможности

### 🏗 Земляные работы
- **Ордер** (284-ПП) - 25 целей из пункта 1.1(1)
- **Плановое уведомление МПГУ** (283-ПП) - 8 целей
- **Плановое уведомление ИАС УГД** (283-ПП) - 12 целей
- **Аварийное уведомление** (1112-ПП) - экстренный порядок

### 📚 Система вопрос-ответ по НПА
База знаний на **100 вопросов** по постановлениям:
- 283-ПП - Уведомительный порядок (25 вопросов)
- 284-ПП - Ордера (25 вопросов)
- 299-ПП - Правила проведения работ (25 вопросов)
- 1112-ПП - Аварийные работы (25 вопросов)

### 💎 Дополнительные функции
- Подписки с апгрейдом/даунгрейдом тарифов
- Триал-период (7 дней)
- Конвертация документов (PDF, Word, Excel)
- OCR распознавание текста
- AI-ассистент 24/7
- Система отзывов и рейтингов
- Личный кабинет со статистикой
- Push-уведомления о новостях
- Реферальная программа

## 🚀 Развертывание на Railway

### Шаг 1: Загрузите файлы на GitHub
```bash
git add .
git commit -m "Update: Earthworks and NPA Q&A system"
git push origin main
```

### Шаг 2: Настройте Railway
1. Создайте проект на [railway.app](https://railway.app)
2. Подключите ваш GitHub репозиторий
3. Добавьте переменные окружения:
   - `BOT_TOKEN` - токен вашего бота от @BotFather
   - `ADMIN_IDS` - ID администраторов через запятую

### Шаг 3: Проверьте работу
Откройте бота в Telegram и проверьте:
- Кнопка "🏗 Земляные работы" работает
- Кнопка "🤖 Вопрос-ответ НПА" работает
- Можно задать любой вопрос из 100

## 🔧 Настройка

### Переменные окружения (.env)
```env
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=123456789,987654321
DATABASE_URL=sqlite:///./bot.db
```

### Добавление новых вопросов в базу знаний

Откройте `earthworks.py` и добавьте в `NPA_KNOWLEDGE_BASE`:

```python
"новый_ключ": {
    "question": "Вопрос пользователя",
    "answer": "Подробный ответ из НПА",
    "source": "284-ПП, пункт X"
}
```
