# 🚀 Расширенные функции бота

Полное руководство по новым возможностям.

## 📋 Что добавлено

### 1. 📧 Уведомления об окончании подписки

**Как работает:**
- Автоматически проверяет подписки каждые 6 часов
- За 3 дня до окончания отправляет напоминание
- В день окончания отправляет срочное уведомление

**Настройка:**
- Работает автоматически после запуска
- Не требует дополнительной настройки

**Пример уведомления:**
```
⏰ Ваша подписка скоро истекает!

Осталось 3 дней.

Продлите подписку, чтобы не потерять доступ ко всем функциям:
• Все возможности сервиса
• Приоритетная поддержка
• Регулярные обновления

Используйте команду /subscribe для продления.
```

### 2. 🎁 Промокоды и скидки

**Команды:**

#### Для пользователей:
- `/promo` - Ввести промокод

#### Для админов:
- `/createpromo` - Создать новый промокод
- `/promos` - Список всех промокодов

**Как создать промокод:**

1. Отправьте команду `/createpromo`
2. Введите код промокода (например, `WELCOME20`)
3. Введите размер скидки в процентах (например, `20`)
4. Введите максимальное количество использований (например, `100`)

**Пример:**
```
Админ: /createpromo
Бот: 🎁 Введите код промокода:
Админ: WELCOME20
Бот: 💰 Введите размер скидки в процентах:
Админ: 20
Бот: 🔢 Введите максимальное количество использований:
Админ: 100
Бот: ✅ Промокод создан!

🎁 Код: WELCOME20
💰 Скидка: 20%
🔢 Использований: 100
```

**Как использовать промокод:**

1. Пользователь отправляет `/promo`
2. Вводит код промокода
3. Получает подтверждение
4. Скидка применяется при оформлении подписки

**Валидация промокодов:**
- Проверка срока действия
- Проверка количества использований
- Проверка повторного использования
- Проверка активности

### 3. 👥 Реферальная программа

**Команда:** `/referral`

**Как работает:**

1. Пользователь отправляет `/referral`
2. Получает уникальную реферальную ссылку
3. Делится ссылкой с друзьями
4. Когда друг регистрируется и оплачивает подписку:
   - Пригласивший получает +7 дней подписки
   - Друг получает скидку 10% на первую оплату

**Пример реферальной ссылки:**
```
https://t.me/your_bot?start=ref_REF123ABC456
```

**Статистика:**
- Количество приглашенных
- Количество активированных бонусов

**Настройка:**
- Бонусные дни: 7 (изменяется в `referrals.py`)
- Скидка для друга: 10% (настраивается в коде)

### 4. 💬 Поддержка пользователей

**Команда:** `/support`

**Для пользователей:**

1. Отправляет `/support`
2. Выбирает "Написать в поддержку"
3. Описывает проблему
4. Получает номер обращения
5. Получает ответ от админа

**Для админов:**

1. Получает уведомление о новом обращении
2. Может ответить на обращение
3. Может закрыть обращение

**Статусы обращений:**
- 🟢 `open` - Открыто
- 🟡 `in_progress` - В работе
- ✅ `closed` - Закрыто

**Команды админа:**
- `/tickets` - Список открытых обращений

**Пример диалога:**

```
Пользователь: /support
Бот: 💬 Поддержка
     Выберите действие: [Написать в поддержку] [Мои обращения]

Пользователь: [Написать в поддержку]
Бот: ✍️ Опишите вашу проблему:

Пользователь: Не работает оплата
Бот: ✅ Ваше обращение #123 принято!
     Мы ответим в течение 2 часов.

[Админу приходит уведомление]
Бот: 🎫 Новое обращение #123
     👤 От: @username
     💬 Сообщение: Не работает оплата
     [Ответить] [Закрыть]

Админ: [Ответить]
Бот: ✍️ Введите ответ:

Админ: Проверьте, пожалуйста, баланс карты
Бот: ✅ Ответ отправлен!

[Пользователю приходит ответ]
Бот: 💬 Ответ на обращение #123
     Проверьте, пожалуйста, баланс карты
```

## 🛠 Установка и настройка

### Шаг 1: Загрузите новые файлы

Загрузите на GitHub следующие файлы:

1. Перейдите в **Deployments**
2. Нажмите **⋮** → **Redeploy**
3. Дождитесь завершения сборки

Отправьте боту команды:
- `/start` - должно появиться новое меню с кнопками
- `/referral` - должна появиться реферальная ссылка
- `/support` - должно появиться меню поддержки
- `/promo` - должен появиться ввод промокода

## 🔧 Настройка параметров

### Изменить бонусные дни за реферала

В файле `referrals.py` найдите:
```python
bonus_days=7
```
Измените на нужное количество дней.

### Изменить частоту проверок уведомлений

В файле `notifications.py` найдите:
```python
await asyncio.sleep(6 * 60 * 60)  # 6 часов
```
Измените на нужное количество секунд.

### Изменить скидку для реферала

В файле `bot_extended.py` найдите функцию `register_referral` и добавьте:
```python
# Создать промокод на 10% для друга
create_promo_code(
    code=f"FRIEND{referred_user_id}",
    discount_percent=10,
    max_uses=1
)
```

## 🐛 Troubleshooting

### Проблема: Уведомления не отправляются

**Решение:**
1. Проверьте логи Railway
2. Убедитесь, что `notification_scheduler` запущен
3. Проверьте, что у пользователей есть активные подписки

### Проблема: Промокод не работает

**Решение:**
1. Проверьте, что промокод активен: `/promos`
2. Проверьте срок действия
3. Проверьте количество использований
4. Убедитесь, что пользователь еще не использовал этот промокод

### Проблема: Реферальная ссылка не работает

**Решение:**
1. Проверьте, что ссылка имеет формат: `https://t.me/bot_username?start=ref_CODE`
2. Убедитесь, что `bot_username` правильный
3. Проверьте логи на наличие ошибок

### Проблема: Обращения не доходят до админа

**Решение:**
1. Проверьте, что `ADMIN_IDS` правильно настроен
2. Проверьте логи Railway
3. Убедитесь, что админ запустил бота
